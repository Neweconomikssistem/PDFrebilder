# PDF OCR — один EXE

Локальная Windows-программа для распознавания сканированных PDF.

После обработки создаётся файл:

`имя_OCR.pdf`

В нём сохраняются исходные страницы, а поверх добавляется невидимый
текстовый слой. Поэтому текст можно искать, выделять и копировать.

## Что требуется

- Windows 10/11 x64
- Python 3.11–3.13 только для сборки
- Tesseract OCR для Windows — только для сборки
- интернет нужен только при первой установке Python-пакетов

Готовый EXE после сборки работает локально и интернет ему не нужен.

## Сборка одного EXE

### 1. Установить Tesseract

Официальная документация Tesseract указывает, что для Windows доступны
сторонние сборки UB Mannheim; официального нового Windows-инсталлятора
от самого проекта сейчас нет.

Страница загрузок:

https://tesseract-ocr.github.io/tessdoc/Downloads.html

Установите Tesseract в Windows.

### 2. Скопировать Tesseract в проект

Создайте:

`vendor\tesseract\`

и скопируйте туда содержимое установленного Tesseract.

В результате должно быть примерно:

vendor\
  tesseract\
    tesseract.exe
    *.dll
    tessdata\
      rus.traineddata
      eng.traineddata
      osd.traineddata
      ...

### 3. Запустить

Дважды нажмите:

`build_windows.bat`

После сборки:

`dist\PDF_OCR.exe`

Это **один EXE**, который содержит Python-программу, Tesseract,
языковые модели и необходимые компоненты.

## Использование

1. Запустить `PDF_OCR.exe`.
2. Нажать «Выбрать PDF…».
3. Выбрать скан.
4. Нажать «РАСПОЗНАТЬ».
5. Рядом с исходным PDF появится `*_OCR.pdf`.

## Языки

Сейчас включены:

- русский
- английский

Основной режим:

`rus+eng`

Позже можно добавить немецкий, казахский и другие языки.

## Важное ограничение первой версии

Эта версия делает именно OCR-текстовый слой. Она не пытается идеально
восстановить редактируемую структуру Word, таблицы или сложную верстку.

Следующая версия может добавить:

- drag & drop PDF;
- выбор языка;
- пакетную обработку нескольких PDF;
- экспорт TXT/DOCX;
- распознавание таблиц;
- автоматический поворот страниц;
- выравнивание/очистку сканов;
- просмотр страниц и найденного текста.

## Сборка EXE без Windows (GitHub Actions)

Если под рукой нет Windows-машины:

1. Создайте репозиторий на github.com (можно приватный — лимита бесплатных
   минут Actions хватает на десятки сборок в месяц; для публичного лимитов нет).
2. Загрузите в него все файлы проекта, включая папку `.github`.
3. Откройте вкладку **Actions** → «Build Windows EXE» → **Run workflow**.
4. Через ~5 минут в завершённом запуске появится блок **Artifacts** —
   скачайте `PDF_OCR`, внутри готовый `PDF_OCR.exe`.

Сборочная машина сама ставит Tesseract, докачивает русские языковые данные
и запускает PyInstaller — локально ничего устанавливать не нужно.
